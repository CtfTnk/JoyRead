# 欣阅使用手册

[English](MANUAL.md) · [简体中文](MANUAL.zh-CN.md) · [日本語](MANUAL.ja.md)

欣阅（JoyRead）是一款本地漫画、连环画和 PDF 阅读器，也能管理个人书库。
书籍及其管理数据保存在你自己的电脑上，无需注册账户，也不会上传书籍。

## 开始使用

从 [Releases 页面](https://github.com/CtfTnk/JoyRead/releases)下载适合系统的安装包：
macOS Apple Silicon 使用 DMG，Windows x64 使用 EXE 安装程序，Ubuntu amd64/arm64 使用 DEB。
在 macOS 上打开 DMG，将 JoyRead 拖入「应用程序」；在 Windows 上运行安装程序。
Ubuntu 请使用终端安装：在下载目录执行 `sudo apt install ./package.deb`，
将 `package.deb` 替换为实际文件名。图形安装器可能卡在**「正在准备」**，该问题尚未修复。
签名和首次启动说明请参阅对应版本的发布说明。

首次启动会创建空书库并显示书架。书库窗口先出现，书籍随后在后台加载；
加载期间仍可使用设置和**操作 → 打开书籍**。
通过系统的「打开方式」打开文件时，会直接进入阅读器，不加载书库，也不导入文件。
之后仍可打开书库，无需关闭正在阅读的外部文件。

Windows 的**设置 → 通用 → 后续窗口加速补偿**中，**启用后台功能**默认开启。
第一次关闭最后一个窗口时，会提示 JoyRead 可在后台保持就绪，以加快后续打开速度。
选择**确认并保持后台运行**会关闭窗口、保留后台进程；选择**退出 JoyRead**会彻底退出。
勾选**后续不再提示**并确认保持运行，可关闭之后的提醒；按 Esc 会取消关闭，保留窗口。

任务栏通知区图标可重新打开 JoyRead。右键菜单可以打开主界面、选择漫画或 PDF 直接阅读而不导入、
查看当前物理内存占用（MB）、清理可重新生成的内存缓存，或彻底退出。
清理会等待所有窗口关闭、后台任务结束。关闭后台功能后，最后一个窗口关闭时程序会正常退出。
再次开启该功能会重置提醒，下次关闭最后一个窗口时会再次说明后台行为。

同一 Windows 专属设置组还提供**自动清理内存缓存**和以秒计的**空闲清理时间**。
自动清理默认开启，在所有窗口关闭 60 秒后尝试清理；若仍有后台任务则等待完成。
延迟可设为 1–3600 秒。关闭自动清理后，托盘中的手动清理仍可使用。
后台功能关闭时，自动清理开关不可用；两个开关都开启后才能设置延迟。
默认阅读偏好、归档与缓存中的从属设置，也会在上级开关关闭时变灰并停用。
JoyRead 不会因此设置 Windows 登录自启动。

主窗口左侧是侧栏，右侧是书架。侧栏包含**书架**下的**全部、最近阅读、我的收藏、已隐藏**，
以及**书单**和**设置**。左上方工具栏按钮可收起侧栏，腾出更多空间。

## 添加书籍

欣阅支持 ZIP/CBZ、7z/CB7、RAR/CBR 和 PDF。直接阅读和导入书库有不同用途。

**只打开，不导入。** **操作 → 打开书籍**直接读取文件当前位置的内容，
不会复制文件，也不会添加到书架，适合临时阅读。

**导入书库。** **操作 → 打开并导入**会立即打开原文件，同时在后台导入托管副本。
书库显示带有**取消**按钮的进度对话框；取消导入或导入失败，都不会关闭阅读器。
**操作 → 导入 → 导入文件… / 导入文件夹…**只导入，不自动打开阅读器。
导入的书籍会复制到 JoyRead 管理的书库目录，之后移动或删除原始文件不影响书库副本。

**导入文件夹…**默认只向下查找一层。若目录嵌套较深，可在设置 → 通用中增加**导入文件夹层级**。

也可以把支持的文件拖到书库窗口。将一个文件放到**阅读**区域即可直接阅读；
如果希望这种拖放同时导入副本，可启用设置 → 通用中的**拖到书库的“阅读”区时同时导入**。
把文件或文件夹放到**导入**区域则只导入。阅读区域不接受多个文件或文件夹。
书库不可用时，阅读区域标明只读，导入区域不可用。

注册文件关联后，可在系统的**打开方式**菜单中选择 JoyRead。
该操作始终只读取文件，不受拖放导入偏好影响；**操作 → 打开书籍**也始终不导入。

带密码的漫画既不能阅读也不能导入，见[加密压缩包](#加密压缩包)。
可以在书库进度对话框中取消正在进行的导入，此前已经完成的导入会保留在书库中。

### 元数据和书籍详情

压缩漫画内受支持的 `meta.json` 或 `ComicInfo.xml` 可提供标题、作者、标签和语言。
欣阅使用其中能够识别的字段；缺少或无法读取的信息会回退到文件名或默认值。
这些数据来自书内元数据，不是联网检索。

在**详情**中，双击标题或作者即可编辑，按 Enter 保存，按 Esc 或移开焦点取消。
双击语言可重新选择，双击封面可打开封面编辑器。封面修改单独保存，不修改原书。
工具栏中的卡片/列表切换按钮，可在封面浏览和紧凑列表之间切换。

### 导入时转换

固实压缩的 7z、嵌套压缩包等格式，逐页读取的成本可能较高。
导入时，JoyRead 可将符合条件的未加密压缩包转换成书库中的 CBZ 副本，原始文件保持不变。
这项导入转换与阅读时可重新生成的页面缓存是两回事。带密码的压缩包既不能阅读也不能导入。

在设置 → 通用中，**导入时转换压缩包**决定转换策略：

| 选项 | 行为 |
| --- | --- |
| 从不转换 | 导入副本保留原始压缩格式。 |
| 仅低速与嵌套格式（默认） | 只转换需要处理的低速或嵌套格式。 |
| 始终转换 | 导入时全部转换，包括普通 ZIP/CBZ。 |

支持的压缩包不必先转换才能阅读。未转换的书籍仍可使用普通阅读缓存，
实际速度取决于源格式和已有缓存页面。

## 书架

每本书以封面卡片显示。点击可打开阅读；其他操作在书籍的**更多**菜单中：

- **阅读**：打开书籍。
- **加入收藏 / 取消收藏**：控制是否出现在「我的收藏」中。
- **详情**：查看标题、作者、语言、书籍类型、标签，或编辑封面。
- **加入…**：加入书单。
- **导出**：将托管文件复制到指定文件夹。
- **移除**：移除书库记录，保留文件。
- **隐藏 / 取消隐藏**：移入或移出[隐藏空间](#隐藏空间)，隐藏的书籍会被加密；仅在隐藏空间解锁时显示。
- **删除**：删除书库记录及由应用管理的文件副本。

「删除」不可撤销，操作前会确认；「移除」只删除 JoyRead 的书库记录，不删除文件。

工具栏中的**搜索**按标题和作者匹配。**排序**可按添加时间、标题或作者升序/降序排列，
也可使用**自定义**顺序。格式筛选可限制为 CBZ、CBR、ZIP、RAR、7Z、PDF 中的一种，
标签按钮可按标签筛选。排序、筛选和搜索条件在重启后保留。

### 自定义顺序与选择

全部、我的收藏、隐藏空间和各个书单分别记忆自己的排序偏好与自定义顺序；
最近阅读始终按阅读时间排列。第一次选择自定义排序时，新加入书库的书在前；
之后切回自定义会恢复已保存的顺序。自定义模式下升序/降序按钮不可用。
新加入的成员放在最前方；取消收藏后重新收藏、移出书单后重新加入，也会回到最前方。
搜索、筛选和隐藏状态不会清除已保存的位置。

点击书籍可单独选中；Shift 点击可加入选择或取消选中。
点击书架空白处、工具栏空白或标题区域可清除选择，Shift 点击空白则保留选择。
从空白处拖动可框选；Shift 拖动即使从书籍上开始，也会进行框选，并将相交书籍加入原选择，
不会开始排序。框选时可使用滚轮，Esc 会恢复操作前的选择。

在自定义排序下，先清空搜索、格式和标签筛选，才可拖动排序。
拖动已选中的卡片或列表行，会按当前显示顺序移动整组选中书籍；
拖动未选中的书籍只移动该本书。开始排序拖动前请松开 Shift。
虚线占位标记显示最终插入位置，鼠标旁预览最多显示三张卡片和总选择数量。

拖动时，只有书架顶部和底部的 15% 区域会自动滚动，越靠边速度越快。
预览为原卡片大小的 40%，距指针 5 px，也可以使用滚轮。
在书籍显示区域内松手会保存顺序；在区域外松手、按 Esc，或按住左键时右击会取消。
可以先离开显示区域，再在松手前返回。
切换书架、排序或视图模式，窗口失活，或后台成员/顺序发生变化，都会取消此次拖动。
保存期间暂时不能继续排序；保存失败时会恢复上次保存的顺序并提示错误。

### 显示缩放

JoyRead 分别记忆书库窗口和独立阅读窗口的普通大小。
最大化、全屏和自动适配屏幕不会覆盖这些偏好。
**设置 → 通用 → 窗口大小 → 恢复默认大小**会清除两者的大小偏好，
并将已打开的窗口恢复到默认 1200×860，再根据当前屏幕调整。

在小屏幕上，窗口会适配可用桌面区域并靠左上对齐，避开系统菜单、任务栏或 Dock 保留区域。
最小尺寸为书库 738×600、阅读器 500×706。屏幕小于最小尺寸时，右侧或底部可能超出屏幕，
但标题栏仍保持可操作。窗口位置、最大化和全屏状态不保存；嵌入式阅读使用书库窗口。

展开的搜索框会随窗口变窄，同时保留格式和标签筛选。设置行横向放不下时，
控件会移到说明文字下方；加宽窗口后恢复原布局。

书籍封面、详情和阅读器缩略图面板中的图片会自动适应显示缩放。
将窗口移到另一显示器时，会更新图片分辨率，不改变卡片大小或选择。
自定义封面保留裁剪范围；旧封面在高密度屏幕上显得模糊时，可在该屏幕上从原图重新编辑保存。
找不到原始图片时，会继续使用已有的缓存封面。

鼠标在阅读进度条上停留 180 ms 后可预览对应页面，拖动滑块时立即显示。
气泡不透明度为 80%，上方是缩略图，下方是从 1 开始的页码，并保持在阅读器内。
图片尚未就绪时缩小为加载提示和页码。该预览与缩略图面板共用缓存，可互相复用图片。

在应用窗口内松开拖动，会跳页一次并关闭预览。
按 Esc、按住左键时右击、窗口失活或在窗口外松手，会取消而不跳页。
普通悬停离开时，气泡用 320 ms 淡出；淡出期间返回会立即恢复。
固实或随机读取能力不明的压缩源只使用已有缓存；较远页面可能持续显示加载中，
直到普通阅读或后台缓存准备完成。预览本身不会触发压缩包解压或预热。

详情、阅读器缩略图面板优先加载可见页面，并随滚动调整预读。
回滚时复用最近查看过的缩略图，缓存有固定内存上限，不会一次加载整本长书。
详情、缩略图面板和封面选择器在每张图下方显示从 1 开始的页码，即使图片尚未加载。
点击图片或页码可选择页面，项目之间的空隙不可点击。

菜单会根据当前窗口内的可用空间调整方向，靠近右侧或底部时向左或向上展开，
按钮下拉菜单也可出现在按钮上方。过长菜单可滚动，被截断的文字可通过提示查看完整内容。
移动或调整窗口大小会关闭菜单。

## 书单

点击侧栏的**书架**或**书单**标题，可收起或展开该区域。
收起时箭头向右，展开时向下；获得焦点的标题也支持 Enter 或空格。
按下时标题变暗，拖出后取消按压反馈，在外部松手不触发点击。
两个区域默认展开，重启后保留状态。收起不改变当前书架和选择，
书单区域收起时也隐藏「新建书单」。设置入口始终位于底部。
隐藏空间是否可见仍遵循隐私设置，重新展开也不会改变它。

书单是手动分组，可用于系列、专题或待读列表。点击侧栏的**新建书单**，
再通过书籍的**加入…**菜单添加书籍。同一本书可以加入多个书单。
删除书单只移除分组，书籍仍留在书库。
书单及其中的书籍也可以隐藏，参见[隐藏空间](#隐藏空间)。

## 标签

在书籍**详情**的标签面板中，上方显示该书已拥有的标签，下方列出书库中已有的标签。
搜索框按 Enter 只会筛选已有标签，不会创建新标签。

创建标签请进入**设置 → 标签**，先清空搜索，再点击标签列表末尾的**＋**。
在随后出现的标签名称输入框中填写名称，点击**确认**或在该输入框中按 Enter。
创建后回到书籍的标签面板，将新标签分配给书籍。
为不同书籍使用一致的标签，便可通过工具栏按标签检索。

**设置 → 标签**管理整个书库的标签，可统一重命名或删除。
删除标签会从所有使用它的书籍中移除该标签，不影响书籍本身。
每个书库最多支持 5,000 个标签，以保持标签对话框的响应速度。

## 阅读

点击书籍即可打开。默认在主窗口内阅读；打开**设置 → 通用 → 独立阅读窗口**，
可让每本书使用单独窗口，方便并排比较。

### 翻页与移动

| 操作 | 效果 |
| --- | --- |
| ← / → | 按阅读方向切换上一页或下一页。 |
| ↑ / ↓ | 在超高页面内上下移动；纵向模式下连续滚动。 |
| 滚轮或触控板 | 在超高页面内滚动，或在纵向模式下连续滚动。 |
| 右键 | 显示阅读控件。 |
| F | 阅读时进入全屏。 |
| Esc | 退出全屏、关闭面板或离开阅读器。 |

停止移动指针一段时间后，阅读器顶部栏和页码栏会淡出；移动指针或右击可重新显示。
从主窗口内的阅读器返回书库，也会退出全屏。全屏时点击阅读器的最大化按钮同样会退出全屏。
全屏时页面和阅读栏外缘为直角，退出后恢复窗口圆角。

### 布局

点击阅读控件中的齿轮打开**阅读设置**。**横向模式**和**纵向模式**按书籍保存，
独立的**预加载**设置则应用于所有阅读器。

- **阅读方向**：从右向左、从左向右，或从上向下。
- **启用自定义**：横向和纵向模式各有开关，从属控件只在对应开关开启时生效。
- **单页**：关闭后允许在合适的窗口内自动使用双页。双宽页面会单独显示，避免将封面或跨页图拆开。
  若前面多出一张单页导致后续配对错位，可使用**偏移跨页配对**将整本书的配对错开一页。
- **适配模式**：自动、适配高度、适配宽度或适配整页。
- **间距**：纵向模式下上下相邻页面的距离，范围为 0–200 px。
- **缩放**：纵向模式的缩放比例，范围为 25%–200%；开启纵向适配宽度时不可用。
- **翻页动画**：无或滑动。

横向阅读时，**适配宽度**从长页顶部开始显示。可用滚轮、触控板或 ↑ / ↓ 查看下方，
长按方向键会连续移动，滚动到页边即停止。← / → 仍用于翻页，每个新页面从顶部开始。
调整窗口或进入/退出全屏时，会在页面边界允许的范围内保留位置。
高度不超过窗口的页面仍居中显示。阅读器面板或对话框打开时，上下移动快捷键不生效。

**预加载**默认向前 **4 页**、向后 **8 页**，范围分别为 **0–10** 和 **0–20**。
前后按页码大小定义，与画面从左向右或从右向左无关。
双页模式从当前显示的一组页面之外开始计数；纵向模式按当前阅读位置预读，同时始终加载可见页面。
设为 0 只关闭该侧后台预读，不会关闭显示所需的页面加载。
设置立即同步所有打开的阅读器，并在重启后保留。
缩小预读范围会替换待处理请求，保留有用缓存和当前打开的书。
缓存仍受总内存上限约束，预读页数不是每一页一定驻留内存的保证。

### 在长书中定位

阅读器可打开三个面板：

- **目录**：显示书内目录。PDF 通常提供，多数 CBZ 没有。
- **缩略图**：用小图浏览各页，便于寻找记得画面的页面。
- **书签**：自行添加的位置标记，见下一节。

书库中的书籍会保存阅读位置，再次打开时恢复。
未导入而直接打开的文件，不会在书库中保存阅读进度、书签或逐书设置。

## 书签

阅读书库中的书籍时，可从阅读控件添加当前页书签，再到**书签**面板重命名或删除。
新书签先使用默认名称。书签保存在书库中，不写入或修改原书文件。
备份时请包含书库数据库，以保留这些记录。

## 封面

默认使用第一页作为封面。若要更换，请打开书籍**详情**并选择**编辑封面**：

- **从书籍页面中选择**：选用书内任意页面。
- **导入图片**：选用磁盘上的图片文件。

确认前可调整裁剪和位置。原始文件不变，封面随书库记录单独保存。

## 隐藏空间

隐藏空间会把书籍移出书架并加密。隐藏的书籍不再出现在全部、最近阅读、我的收藏、
普通书单和搜索结果中，只在侧栏**已隐藏**中显示。书籍文件和封面以加密形式保存，
只有使用密码或恢复码才能读取。

### 设置隐藏空间

在**设置 → 隐私 → 隐藏空间**中打开**显示书单**。第一次打开时，JoyRead 会引导你设置：

1. **设置密码**并再次输入确认。密码至少 4 个字符，可使用任意字符。少于 12 个字符时会提示：
   较短的密码能防止他人随手翻看，但复制了你书库的人可能猜出它。可选择**仍然使用**或**重新设置**。
2. **保存恢复码。** 点击**复制**，或用**保存…**写入文件，并把它放在远离书库的安全位置。
3. **再次输入恢复码**，确认已经保存。不区分大小写，空格也不影响。

在任一步取消都不会创建隐藏空间。

忘记密码时，恢复码是唯一的找回方式；隐藏空间没有密码提示。
**如果密码和恢复码都丢失，任何人都无法恢复隐藏的书籍**，JoyRead 的开发者也不能。
每个书库都有各自的隐藏空间、密码和恢复码。

### 隐藏书籍

只有在隐藏空间显示时，书籍**更多**菜单中才会出现**隐藏**和**取消隐藏**。

- **隐藏**：书籍立即移入**已隐藏**，JoyRead 在后台加密。完成前卡片显示**正在加密…**，
  期间可以照常使用 JoyRead。
- **取消隐藏**：书籍会先解密。解密期间显示**正在解密…**并留在已隐藏中，完成后回到书架。

正在显示该书的阅读器会先关闭。隐藏还会把书籍永久移出我的收藏、最近阅读和普通书单，
取消隐藏后不会恢复；标题、标签、阅读位置和书签都会保留。

隐藏改变的是 JoyRead 保存书籍的方式，而不是页面内容：压缩包会以 CBZ 形式保存在加密文件内，
取消隐藏后也以 CBZ 返回；PDF 会原样返回。隐藏空间解锁时可以**导出**隐藏的书籍，
导出结果是保存在你指定位置的普通、未加密的 CBZ 或 PDF。

**书单也可以隐藏。** 右击书单并选择**设为可隐藏**。可隐藏书单只在隐藏空间显示时出现，
并可包含隐藏的书籍；选择**设为普通**可恢复为普通书单。

### 锁定与解锁

以下操作会锁定隐藏空间：

- 关闭**显示书单**
- 关闭书库窗口
- 退出 JoyRead
- 移动书库、选择其他书库或重置书库

锁定时，所有显示隐藏书籍的阅读器都会关闭，JoyRead 也会丢弃已解密的封面。
隐藏空间不会因一段时间无操作或电脑睡眠而自动锁定。

如果关闭书库窗口时**显示书单**仍为开启，下次打开书库窗口时会要求输入密码：

- **解锁**：显示隐藏空间。
- **隐藏**：关闭显示书单，隐藏空间保持锁定。

重新打开显示书单时，也会要求输入密码。

**忘记密码？** 在该界面选择**使用恢复码**，或在密码对话框中选择**恢复码**。
输入恢复码后设置新密码；恢复码仍然有效。

### 隐藏空间设置

**设置 → 隐私 → 隐藏空间**包含：

- **显示书单**：显示或隐藏隐藏空间。关闭时也会锁定。
- **加密**：显示隐藏书籍是否均已加密、仍在加密或解密的数量，以及失败的数量。
  **重试**会再次处理失败的书籍；下次解锁隐藏空间和下次启动 JoyRead 时也会自动重试。
- **修改密码**：需要输入当前密码，恢复码保持不变。
- **新恢复码**：需要输入密码。确认新恢复码之前，旧恢复码仍然有效。
- **全部还原**：输入密码后，解密并取消隐藏所有书籍，并把可隐藏书单恢复为普通书单。
  每本书完成后各自回到书架。
- **重置并清除**：永久删除所有隐藏书籍和所有可隐藏书单，并移除密码和恢复码。该操作不可撤销。
  它不需要密码，因此在密码和恢复码都丢失时，可以用它重新开始。

### 从旧版本升级

旧版 JoyRead 用隐藏空间密码隐藏书籍，但不加密。升级之前，这些书籍保持隐藏但未加密。
下次显示隐藏空间时，JoyRead 会要求输入该密码：

1. 原密码继续作为隐藏空间的密码。
2. 保存并确认恢复码。
3. JoyRead 加密此前隐藏的书籍。

之后可以通过**修改密码**换成更长的密码。取消则不做任何更改。

### 隐藏空间保护什么，不保护什么

**受保护：**

- 隐藏书籍的文件
- 它们的封面
- 阅读时 JoyRead 缓存的页面

JoyRead 不会把解密后的页面或封面写入磁盘。

**不受保护：**

- **书库数据库。** 能读取你文件的人，仍可看到每本隐藏书籍的：
  - 标题和作者
  - 标签和书单名称
  - 原始文件名和位置
  - 阅读进度和书签

  再次导入同一文件时，仍会提示重复。
- **隐藏之前的副本。** 隐藏会删除 JoyRead 保存的未加密副本，但更早的副本可能仍然存在：
  - 书库外的原始文件
  - Time Machine、文件历史记录等备份
  - 文件系统快照
  - 磁盘上已删除但尚未覆盖的数据块

  隐藏部分 RAR 和 7z 书籍时，页面也会在转换期间短暂解压到临时文件夹。
- **解锁期间的内存。** 隐藏空间解锁时，解密的页面和密钥位于内存中；
  操作系统可能在交换或休眠时把内存写入磁盘。
- **较短的密码。** 复制了你书库的人可以离线尝试密码，速度只受其电脑性能限制。
  较短的密码可能在几天内被猜出，4 位数字 PIN 可能只需几分钟。
  如果这对你很重要，请使用 12 个或更多字符。恢复码足够长，不会成为薄弱环节。
- **带密码的压缩包。** JoyRead 无法加密这类压缩包。它们保持隐藏，并标记为**未加密**。

如需保护全部内容（包括书库数据库），请同时把书库放在加密磁盘上，或使用全盘加密。

### 默认阅读偏好

可以预设阅读方向、横向/纵向自定义、单页、适配模式、纵向间距与缩放，以及翻页动画。
这些默认值用于临时文件和未保存独立阅读设置的书库书籍，已有的逐书设置优先。
修改默认值影响之后打开的阅读器，不覆盖已打开阅读器的设置。
当前书籍应通过阅读器内的阅读设置调整。全局预加载是独立设置，见[布局](#布局)。

### 归档与缓存

默认资源限制适合一般书库。遇到特别大的书可以提高相应上限；希望减少资源占用则可以降低。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 限制压缩包大小 / 最大压缩包大小 | 开启，5 GB | 拒绝打开超过上限的压缩包。 |
| 资源保护 | 开启 | 下列四项限制的总开关。 |
| 最大提取项目大小 | 1 GB | 单个页面的最大解压大小。 |
| 单次操作最大提取数据 | 4 GB | 一次解压操作的总数据上限。 |
| 最大图片尺寸 | 400 MP | 拒绝超过 400 百万像素的图片。 |
| 外部解压超时 | 300 s | 内置 7-Zip 的最长执行时间。 |
| 嵌套压缩包深度 | 2 | 允许继续读取的压缩包内嵌套层数。 |
| 压缩包全局文件深度 | 100 | 整本书所有路径嵌套的总深度上限。 |
| 阅读器页面缓存（内存） | 512 MB | 内存中保存的已解码页面。 |
| 缩略图缓存（内存） | 64 MB | 内存中的缩略图。 |
| 压缩包解压池（磁盘） | 5 GB | 页面解压缓存的磁盘预算。 |
| 压缩包缓存策略 | Zip bundle | 每本书保存为一个 ZIP，或使用独立的隐藏图片文件。 |

压缩包声称的大小并不一定可信，例如标记为 2 KB 的内容可能展开成数 GB。
这些限制使异常或恶意压缩包能够以错误提示结束，而不是耗尽内存或磁盘。

**解压池使用情况**显示已占用的磁盘预算，**清除**按钮可以清空。
空间不足时，会淘汰最久未使用的缓存书籍，之后按需重建，因此通常不必手动清空。

## 文件保存位置

以下是安装版的默认位置。若已移动或选择其他书库，请以
**设置 → 隐私 → 存储 → 书库位置**显示的实际路径为准。

### macOS

| 内容 | 位置 |
| --- | --- |
| 书库：书籍、封面、数据库、备份 | `~/Library/Application Support/JoyRead-Library` |
| 配置文件 | `~/Library/Application Support/JoyRead/Config/settings.json` |
| 日志 | `~/Library/Application Support/JoyRead/Logs` |
| 可重新生成的压缩包页面缓存 | `~/Library/Caches/JoyRead` |

### Windows

| 内容 | 位置 |
| --- | --- |
| 书库：书籍、封面、数据库、备份 | `%APPDATA%\JoyRead\JoyRead-Library` |
| 配置文件 | `%APPDATA%\JoyRead\JoyRead\Config\settings.json` |
| 日志 | `%APPDATA%\JoyRead\JoyRead\Logs` |
| 可重新生成的压缩包页面缓存 | `%LOCALAPPDATA%\JoyRead\JoyRead\Cache` |

可将这些路径直接粘贴到文件资源管理器的地址栏。
`%APPDATA%` 通常指向 `C:\Users\<username>\AppData\Roaming`，
`%LOCALAPPDATA%` 通常指向 `C:\Users\<username>\AppData\Local`。
配置和缓存路径中重复的 `JoyRead\JoyRead` 是实际目录结构，并非笔误。

### Ubuntu / Linux

| 内容 | 位置 |
| --- | --- |
| 书库：书籍、封面、数据库、备份 | `~/.local/share/JoyRead-Library` |
| 配置文件 | `~/.config/JoyRead/Config/settings.json` |
| 日志 | `~/.config/JoyRead/Logs` |
| 可重新生成的压缩包页面缓存 | `~/.cache/JoyRead` |

`~` 表示当前用户的主目录。若设置了环境变量，`XDG_DATA_HOME` 会替代 `~/.local/share`，
`XDG_CONFIG_HOME` 会替代 `~/.config`，`XDG_CACHE_HOME` 会替代 `~/.cache`。
日志位于上表所列的配置目录体系内。

### 书库内容与移动

书库内的 `Books/` 保存托管书籍，`Database/joyread.sqlite3` 保存数据库记录，
`Thumbnails/` 保存封面和缩略图，`Backups/` 保存备份。
隐藏的书籍及其封面以 `.jrl` 加密文件保存在 `Books/` 和 `Thumbnails/covers/` 中，只能从书库打开；
移动书库时，隐藏空间会随之移动。
日志目录内包括 `joyread.log` 及轮转日志；自定义翻译位于与 `settings.json` 同属配置目录的 `Config/locales/`。

从源码仓库运行，或使用 `JOYREAD_RUNTIME_DIR` 指定运行目录时，
会改用该仓库或运行目录下的 `JoyRead-Library/`、`.joyread_support/`（配置和日志）及 `.joyread_cache/`。

直接打开但未导入的书籍不在这些目录中，仍位于原处。

**设置 → 隐私 → 存储 → 书库位置**可移动书籍、封面、数据库和备份，也支持外接磁盘。
页面缓存仍保留在应用缓存位置，需要时重新生成。
移动前会先保存并关闭从书库打开的阅读器，独立打开的外部阅读器继续保留。
**选择已有书库**用于选择已经存在的书库目录，适合手动移动后重新指定，或在多个书库之间切换。
使用托管书籍或书库进度的阅读器也会关闭，即使此前曾由系统「打开方式」激活同一窗口。

## 加密压缩包

JoyRead 不打开、也不导入带密码的 ZIP、7z 和 RAR 压缩包。打开时会提示暂不支持带密码的压缩包，
不会要求输入密码。普通压缩包里如果嵌套了带密码的压缩包，仍可打开，只是跳过受保护压缩包里的页面。

要阅读这类书，请先用 7-Zip 等其他工具解压，再打开或导入解压后的文件。
想保护隐私的话，可以导入后将其隐藏：[隐藏空间](#隐藏空间)会在书库中加密这本书。

JoyRead 1.3.1 及更早版本会要求输入密码，但页面缓存会把解出的页面以明文留在磁盘上，
部分格式还会通过命令行把密码交给 7-Zip 助手，同一用户的其他进程可以看到。
在能同时避免这两点之前，阅读带密码压缩包的功能暂时关闭。

## 故障排查

**书库加载不出来。** 文件夹不可用时，书架显示已保存路径、原因及**重试**和**本次跳过**；
数据库加载失败时，对话框提供相同选择。跳过会保留已保存的书库位置，仍可打开外部文件。
可到**设置 → 隐私 → 存储 → 选择已有书库**指定其他有效书库。
JoyRead 不会在启动时自动删除或重置已有的损坏书库。

**提示压缩包超过资源限制。** 文件超过「归档与缓存」中的某项上限。
可提高提示中指出的限制；确认文件可信后，也可关闭资源保护。

**书籍显示缺失。** 应用找不到文件。对导入的书籍而言，常见原因是书库目录被移动，
请检查[书库位置](#文件保存位置)。提示中可选择删除记录或保留记录。

**书籍显示不可用。** 完整性检查发现文件与导入时不同，可能已经损坏，因此不会打开。
可从更多菜单移除该记录，再重新导入。

**翻页很慢。** 常见原因是尚未转换或缓存的固实 7z、RAR 等压缩包。
可将**导入时转换压缩包**设为**始终转换**后重新导入，并检查解压池是否有足够空间。

**隐藏书籍显示未加密或未解密。** JoyRead 未能完成加密或解密，例如磁盘已满，或文件被其他应用占用。
书籍保持原状。排除原因后，在**设置 → 隐私 → 隐藏空间**中选择**重试**；
下次解锁和下次启动时也会自动重试。带密码的压缩包无法加密。

**书库状态不一致。** **设置 → 通用 → 验证书库并清理缓存**检查当前书库的变更、重复、
缺失、孤立文件和未使用的生成封面，显示发现的问题，并在修改前询问。
共享压缩包页面缓存有独立容量限制，可在「归档与缓存」中清除。

**EPUB 打不开。** EPUB 功能尚未完成，因此当前关闭。
参见 [README](../README.zh-CN.md)。

跟随系统会在启动和选中该选项时检测，之后系统语言发生变化，需要重启应用。

语言切换会更新已打开的窗口和控件。中文显示名为「欣阅」，英文为 JoyRead，日文为「ジョイヨミ」。
安装快捷方式、程序文件名、书库和配置目录名不变；系统原生文件对话框按钮可能跟随系统语言。

稳定配置目录 `Config/locales` 中的自定义 JSON 翻译可逐项覆盖内置文字。
缺少或留空的项保留内置译文；内置语言缺失的项回退到英语。
损坏的覆盖文件会被忽略并写入日志。用户填写的标题、标签、路径和技术诊断信息不被翻译。
