<summary><strong>简体中文 · 欣阅 1.3.0</strong></summary>

更快回到阅读，更顺手地打开书籍。欣阅 1.3.0 带来启动体验优化、默认阅读偏好，以及更完善的全屏和适应宽度阅读。

### Windows 专属：再次启动加速

**隆重推出 Windows 专属功能：再次启动加速。**

关闭窗口，下一次阅读仍然随时就绪。新的后台模式让欣阅保留在系统托盘中，再次打开书库或通过资源管理器打开漫画、PDF 时，可复用正在运行的进程，减少重复启动的等待。

- **关闭窗口，保持就绪：** 后台模式默认开启。首次关闭最后一个窗口时，可选择「保持运行」或「退出欣阅」。在设置 → 通用中可关闭后台模式，恢复关闭最后一个窗口即退出。
- **从托盘继续阅读：** 重新打开书库，选择漫画或 PDF 直接阅读、无需导入，查看当前内存占用，手动清理内存缓存，或彻底退出。
- **自动清理闲置内存：** 默认在所有窗口关闭 60 秒后清理可重建的内存缓存；若仍有后台任务，则等待任务完成。延迟可设为 1–3600 秒，也可关闭自动清理。此功能不会设置 Windows 登录自启动。

### 其他更新

- **更轻快的启动：** 从系统「打开方式」打开文件时直接进入阅读器，无需先加载书库。正常启动时先显示书库窗口，书籍在后台载入，设置和直接打开书籍仍可使用。
- **打开与导入更清晰：** 直接打开文件不会复制或入库；「打开并导入」可边读边导入，并支持取消。拖到书库「阅读」区域时是否同时导入，可单独设置。
- **默认阅读偏好：** 在设置中预设阅读方向、布局等选项，用于临时打开的文件和未保存独立阅读设置的书籍；已有书籍偏好继续保留。
- **全屏与长页阅读：** 按 F 进入全屏，Esc 退出；全屏时页面与阅读器边缘使用直角。横向阅读的「适应宽度」支持滚轮、触控板和 ↑ / ↓ 上下移动，长按可连续移动；到页边停止，左右翻页后从新页顶部开始。调整窗口或切换全屏时尽量保留阅读位置。
- **更稳定的书库切换：** 独立打开的外部书籍在切换书库时继续阅读；依赖旧书库的阅读器会先保存再关闭。改善加载失败后的重试，减少调整窗口和无关设置时的重复加载。
- **界面细节优化：** 改善 Windows 窗口前台激活与菜单边缘，补齐中日文字体 Medium 字重，并让不可用的从属设置统一变灰。

### 下载与安装

在本页底部的 **Assets（附件）** 中选择安装包：

| 系统 | 安装包 | 要求 |
| --- | --- | --- |
| macOS · Apple Silicon | `JoyRead-1.3.0-macos-arm64.dmg` | macOS 13+，不提供 Intel 版本 |
| Windows · x64 | `JoyRead-1.3.0-windows-x86_64-setup.exe` | Windows 10/11 x86-64 |
| Ubuntu / Linux · amd64 | `JoyRead-1.3.0-linux-amd64.deb` | 基于 Ubuntu 22.04 构建 |
| Ubuntu / Linux · arm64 | `JoyRead-1.3.0-linux-arm64.deb` | 基于 Ubuntu 22.04 构建 |

`SHA256SUMS` 提供安装包校验值；`build-info.json` 记录版本、源代码提交与各平台构建来源。Linux 包并不保证兼容所有发行版。

**macOS 首次启动指南：** 打开 DMG，把 JoyRead 拖进**应用程序**文件夹，再从该文件夹启动。应用使用 ad-hoc 签名，尚未经过 Apple 公证。如果系统提示无法验证应用，在确认下载来源后：

1. 点击**「完成」**，不要点击「移到废纸篓」。
2. 打开**苹果菜单 → 系统设置 → 隐私与安全性**。
3. 在**「安全性」**中找到 JoyRead 被阻止的提示。
4. 点击**「仍要打开」**，按提示确认或验证身份。

安装新副本后可能需要再次确认。如果 Launchpad 尚未显示，请先从「应用程序」直接打开。

**Windows：** 运行 EXE 安装程序。安装包没有受信任的代码签名；如果出现 SmartScreen 提示，确认来源后选择**「更多信息 → 仍要运行」**。

**Ubuntu：** 在下载目录打开终端，按架构选择命令。图形安装器仍可能卡在“正在准备”，请使用 APT：

```bash
# amd64 / x86-64
sudo apt install ./JoyRead-1.3.0-linux-amd64.deb
# arm64
sudo apt install ./JoyRead-1.3.0-linux-arm64.deb
```

<summary><strong>日本語 · ジョイヨミ 1.3.0</strong></summary>

すばやく読書に戻り、もっと手軽に本を開く。ジョイヨミ 1.3.0 では、起動の改善、既定の読書設定、全画面表示と幅に合わせた表示の操作を追加しました。

### Windows 限定：2 回目以降の起動を高速化

**Windows 限定の新機能として、2 回目以降の起動高速化をご紹介します。**

ウィンドウを閉じても、次の読書に備えて待機します。新しいバックグラウンドモードでは通知領域に常駐し、ライブラリを再び開く場合や、エクスプローラーから漫画・PDF を開く場合に、実行中のプロセスを再利用して起動の待ち時間を減らします。

- **閉じても待機：** 初期設定で有効です。最後のウィンドウを初めて閉じる際に、実行を続けるかジョイヨミを終了するかを選べます。設定 → 一般で無効にすると、最後のウィンドウを閉じた時点で終了します。
- **トレイから読書を再開：** ライブラリを開く、漫画や PDF を取り込まずに読む、現在のメモリ使用量を確認する、メモリキャッシュを手動で解放する、完全に終了する操作ができます。
- **待機中のメモリを自動解放：** 初期設定では、すべてのウィンドウを閉じてから 60 秒後に再生成可能なメモリキャッシュを解放します。バックグラウンド処理が残っている場合は完了を待ちます。待機時間は 1–3600 秒に変更でき、自動解放を無効にもできます。Windows ログイン時の自動起動は設定しません。

### その他の更新

- **軽快な起動：** OS の「プログラムから開く」ではライブラリを先に読み込まず、直接リーダーを開きます。通常起動ではライブラリのウィンドウを先に表示して本をバックグラウンドで読み込み、その間も設定や本を直接開く操作が使えます。
- **開く操作と取り込みを整理：** 直接開くだけではファイルをコピーしたり蔵書へ追加したりしません。「開いて取り込む」では読みながら取り込め、取り込みをキャンセルできます。ライブラリの「読む」領域へのドロップ時に取り込むかどうかも個別に設定できます。
- **既定の読書設定：** 読む方向やレイアウトなどを設定画面で指定し、一時的に開いたファイルや個別設定のない本に適用できます。保存済みの本ごとの設定は維持されます。
- **全画面表示と縦長ページ：** F で全画面に入り、Esc で戻ります。全画面ではページとリーダーの外周を角丸なしで表示します。横方向の読書で「幅に合わせる」を選ぶと、ホイール、トラックパッド、↑ / ↓ で上下に移動でき、キーの長押しにも対応します。ページ端で止まり、左右キーでページをめくると新しいページの先頭から表示します。サイズ変更や全画面の切り替え時も、可能な範囲で読書位置を維持します。
- **ライブラリ切り替えを安定化：** 独立して開いた外部ファイルは切り替え中も読み続けられます。元のライブラリに依存するリーダーは保存してから閉じます。読み込み失敗時の再試行を改善し、サイズ変更や無関係な設定変更による重複読み込みを減らしました。
- **UI の調整：** Windows でのウィンドウの前面表示とメニューの縁を改善し、中国語・日本語フォントの Medium ウェイトを追加しました。無効な従属設定は一貫してグレー表示になります。

# JoyRead 1.3.0

Get back to reading faster. JoyRead 1.3.0 brings a smoother startup experience, default reading preferences, and better fullscreen and fit-to-width reading.

## Windows exclusive: faster subsequent launches

**Proudly introducing a Windows exclusive: faster subsequent launches.**

Close the window. Stay ready for your next read. The new background mode keeps JoyRead in the notification area, reusing the running process when you reopen the Library or open a comic or PDF from Explorer, so there is less startup work to wait for.

- **Close and stay ready:** background mode is enabled by default. The first time you close the last window, choose **Keep running** or **Quit JoyRead**. Disable it in Settings → General to exit when the last window closes.
- **Pick up from the tray:** reopen the Library, choose a comic or PDF to read without importing, view current memory usage, clear memory caches, or quit completely.
- **Automatic idle cleanup:** by default, rebuildable memory caches are cleared 60 seconds after all windows close, waiting for any remaining background work to finish. Set the delay to 1–3600 seconds or disable automatic cleanup. This feature does not enable startup at Windows sign-in.

## What's new across platforms

- **A lighter startup:** opening a file through your system's Open With goes straight to its Reader without loading the Library first. A normal launch shows the Library window before loading books in the background; settings and direct book opening remain available.
- **Clearer open and import choices:** opening a file in place does not copy it or add it to your Library. Open & Import lets you read while a cancellable import runs. A separate preference controls whether dropping a file onto the Library's Read zone also imports it.
- **Default reading preferences:** choose reading direction, layout, and other defaults for temporary files and books without saved individual settings. Existing per-book preferences remain in place.
- **Fullscreen and tall-page reading:** press F for fullscreen and Esc to leave, with square page and reader edges in fullscreen. In horizontal Fit to Width, use the wheel, trackpad, or ↑ / ↓ to move vertically; hold an arrow to keep moving. Scrolling stops at page edges, while left/right page turns start the new page at the top. Resizing or switching fullscreen preserves your position where page bounds allow.
- **More reliable Library switching:** independently opened external books stay usable while switching libraries. Readers tied to the old Library save before closing. Recovery retries use the selected Library, and window resizing or unrelated settings changes avoid unnecessary reloads.
- **UI refinements:** improved Windows foreground activation and menu edges, bundled Medium-weight Chinese/Japanese fonts, and consistent dimming of unavailable dependent settings.

## Upgrade and compatibility

Upgrading from 1.2.0 adds no database migration. Your library, collections, tags, custom order, covers, reading progress, and existing per-book settings are retained. Back up your library before upgrading. Windows background mode and automatic idle memory cleanup are enabled by default and can be changed in General settings. ZIP/CBZ, 7z/CB7, RAR/CBR, and PDF remain supported; EPUB remains disabled.
