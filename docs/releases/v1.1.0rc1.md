# JoyRead 1.1.0rc1 — Release candidate

**Unpublished candidate for v1.1.0.** Intended for testing before the stable
release. No downloadable candidate assets have been published yet.

## English

### What's new

- **Custom shelf order:** All, Favourites, Hidden Space and individual collections
  remember their own order and sort preference. New members appear at the front;
  Recent keeps reading-time order. Search and filters preserve saved positions.
- **Selection and dragging:** grid and list both support rectangle selection.
  Shift-click toggles selection; Shift-drag selects even when started on a book.
  Drag without Shift to reorder in unfiltered Custom mode. Selected books move
  in their displayed order, with one insertion placeholder and up to three
  preview cards. Esc, right-click while holding left, or release outside cancels.
- **Smoother interaction:** reuse cards and rows, update only changed content,
  cache blurred snapshots, and smoothly blend the file-drop confirmation state.
  Disabled switches show neither side selected.
- **Sharper thumbnails:** bookshelf covers, Detail thumbnails and Reader Topic
  thumbnails follow window pixel density. Display changes preserve selection,
  scroll/reading position and existing images while replacements load.
- Drag previews use 40% card size and a 5 px pointer gap. Auto-scroll activates
  only in the top/bottom 15% of the shelf, reaching 120 px/s at the edge.

### Upgrade and testing notes

- This candidate adds database migration 14 for scoped sorting. Back up the
  library before testing; restore the backup if returning to the older release.
- Existing custom cover crops remain authoritative. Old low-resolution custom
  covers need to be saved again from their original source for native sharpness.
- EPUB remains disabled. Supported manga/archive/PDF workflows remain in scope.
- Native Windows/Ubuntu gesture behavior, physical mixed-DPI monitor moves,
  and installer upgrade/uninstall checks remain pending for this candidate.
- macOS remains Apple Silicon only. Existing signing/notarization and Linux
  graphical-installer limitations from 1.0.2 still apply.

## 简体中文

这是 **v1.1.0 的首个候选版**，尚未发布下载资源，用于正式版前的验证。

- **自定义排序：** 全部、收藏、隐藏空间及各合集独立记忆顺序与排序偏好；新增项前置，最近阅读仍按阅读时间排列。
- **框选与多选拖动：** 网格和列表均支持。Shift 单击切换选中，Shift 拖动从卡片上也能框选；不按 Shift 时可在无筛选的自定义模式中拖动排序。移动组保持原显示顺序。
- **交互更顺滑：** 复用卡片与列表行，差量更新内容；模糊快照缓存，确认动画平滑过渡；禁用 switch 两侧均不突出选中。
- **HiDPI：** 封面、详情页及 Reader Topic 内页缩略图随窗口像素密度生成；跨屏刷新保留选择、滚动位置与阅读位置。
- 拖动预览为卡片的 40%，指针间距 5 px；仅上下各 15% 区域自动滚动，边缘最高 120 px/s。Esc、按住左键时右击、区域外松手均可取消。

本版会升级书库到数据库迁移 14，试用前请备份书库，回退旧版时恢复备份。
旧的低清手工裁剪封面需从原图重新保存。EPUB 继续禁用。
Windows／Ubuntu 原生拖动、实机跨屏及安装升级／卸载仍待验证；1.0.2 已有的签名、公证和 Linux 图形安装器限制仍适用。

## 日本語

**v1.1.0 の最初のリリース候補**です。ダウンロード用パッケージはまだ公開されていません。

- **カスタム順序：** すべて、お気に入り、非表示スペース、各コレクションで順序と並び替え設定を個別に保存。追加した本は先頭に入り、最近読んだ本は読書日時順を維持します。
- **範囲選択と複数ドラッグ：** グリッド／リストに対応。Shift クリックで選択を切り替え、Shift ドラッグは本の上からでも範囲選択。不絞り込みのカスタム順序では、Shift を離してドラッグすると表示順を保って移動します。
- **滑らかな表示：** カード／行を再利用して差分更新し、ぼかし画像をキャッシュ。ファイルドロップの確認状態へ滑らかに移行します。無効なスイッチでは選択側を強調しません。
- **HiDPI：** 表紙、詳細パネル、Reader Topic のサムネイルがウィンドウのピクセル密度に対応。画面間移動でも選択・スクロール・読書位置を保持します。
- ドラッグ表示は 40%、ポインターから 5 px。自動スクロールは上下 15% の範囲で動作し、端では最大 120 px/s。Esc、左ボタンを押しながら右クリック、領域外で離す操作でキャンセルできます。

データベース移行 14 を適用するため、試用前に蔵書をバックアップしてください。
旧版へ戻す際はバックアップを復元します。低解像度の編集済み表紙は元画像から再保存してください。
EPUB は引き続き無効です。Windows／Ubuntu の実機操作、異なる DPI の画面間移動、インストール更新／削除の検証は未完了です。1.0.2 の署名・公証・Linux GUI インストーラーに関する制限も引き続き適用されます。
