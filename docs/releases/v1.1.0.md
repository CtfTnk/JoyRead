# JoyRead 1.1.0

Custom shelf ordering, smoother interaction, and sharper HiDPI thumbnails.

## English

### What's new

- **Custom shelf order:** All, Favourites, Hidden Space and individual collections
  remember their own order and sort preference. New members appear at the front;
  Recent keeps reading-time order. Search and filters preserve saved positions.
- **Selection and dragging:** grid and list both support rectangle selection.
  Shift-click toggles selection; Shift-drag selects even when started on a book.
  Drag without Shift to reorder in unfiltered Custom mode. Selected books move
  in their displayed order, with one insertion placeholder and up to three
  preview cards. Esc, right-click while holding left, or release outside cancels.
- **Smoother interaction:** reuse cards and rows, update only changed content,
  cache blurred snapshots, and smoothly blend the file-drop confirmation state.
  Disabled switches show neither side selected.
- **Sharper thumbnails:** bookshelf covers, Detail thumbnails and Reader Topic
  thumbnails follow window pixel density. Display changes preserve selection,
  scroll/reading position and existing images while replacements load.
- Drag previews use 40% card size and a 5 px pointer gap. Auto-scroll activates
  only in the top/bottom 15% of the shelf, reaching 120 px/s at the edge.

### Upgrade and testing notes

- This release adds database migration 14 for scoped sorting. Back up the
  library before upgrading; restore the backup if returning to the older release.
- Existing custom cover crops remain authoritative. Old low-resolution custom
  covers need to be saved again from their original source for native sharpness.
- EPUB remains disabled. Supported manga/archive/PDF workflows remain in scope.
- Native Windows/Ubuntu gesture behavior, physical mixed-DPI monitor moves,
  and installer upgrade/uninstall checks remain pending for this release.
- macOS remains Apple Silicon only. Existing signing/notarization and Linux
  graphical-installer limitations from 1.0.2 still apply.

### macOS installation — English

These are the first-launch instructions carried forward from v1.0.1.
Open the DMG and drag JoyRead into **Applications**. Launch JoyRead from there.
The app is ad-hoc signed and **not Apple-notarized**. If macOS says Apple could
not verify that JoyRead is free of malware, and you have verified the download
source:

1. Click **Done**, not **Move to Bin**.
2. Open **Apple menu → System Settings → Privacy & Security**.
3. Scroll to **Security** and find the JoyRead blocked-app notice.
4. Click **Open Anyway**, then confirm/authenticate when prompted.

A newly installed copy may require this approval again. If it is missing from
Launchpad, first try opening it directly from Applications.

### macOS 安装指南 — 简体中文

沿用 v1.0.1 的首次启动指南：打开 DMG，把 JoyRead 拖进**应用程序**文件夹，再从该文件夹启动。

4. 点击**「仍要打开」**，按系统提示确认或验证身份。

安装新副本后可能需要再次确认。如果 Launchpad 暂时没有显示，请先从「应用程序」文件夹打开一次。

### Windows / Ubuntu

Windows: run the EXE installer. If SmartScreen warns, verify the source before
choosing **More info → Run anyway** / **更多信息 → 仍要运行** / **詳細情報 → 実行**.

Ubuntu: use APT, not the graphical installer, which may remain at “Preparing”.
Choose the command matching your architecture:

```bash
# amd64 / x86-64
sudo apt install ./JoyRead-1.1.0-linux-amd64.deb
# arm64
sudo apt install ./JoyRead-1.1.0-linux-arm64.deb
```

中文：Ubuntu 请在终端使用对应架构的 APT 命令安装，图形安装器仍可能卡在“正在准备”。
日本語：Ubuntu では対応するアーキテクチャの APT コマンドを使用してください。GUI インストーラーは「準備中」で停止することがあります。
