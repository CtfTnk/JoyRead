# ジョイヨミ ユーザーマニュアル

[English](MANUAL.md) · [简体中文](MANUAL.zh-CN.md) · [日本語](MANUAL.ja.md)

ジョイヨミ（JoyRead）は、漫画・コミック・PDF を読むためのローカルアプリで、蔵書の管理もできます。
本と管理情報は自分のパソコンに保存されます。アカウント登録は不要で、本をアップロードすることもありません。

## はじめに

[Releases ページ](https://github.com/CtfTnk/JoyRead/releases)から、使用するシステムに合うパッケージをダウンロードします。
macOS Apple Silicon は DMG、Windows x64 は EXE インストーラー、Ubuntu amd64/arm64 は DEB を使用します。
macOS では DMG を開いて JoyRead を「アプリケーション」へドラッグし、Windows ではインストーラーを実行します。
Ubuntu ではダウンロード先でターミナルを開き、`sudo apt install ./package.deb` を実行してください。
`package.deb` は実際のファイル名に置き換えます。GUI インストーラーが**「準備中」**で止まる問題は未解決です。
署名と初回起動の手順は、各バージョンのリリースノートを参照してください。

初回起動では空のライブラリを作成して本棚を表示します。
ライブラリのウィンドウを先に表示し、本はバックグラウンドで読み込みます。
読み込み中も設定と**アクション → 書籍を開く**を使用できます。
OS の「プログラムから開く」では、ライブラリを読み込んだり本をインポートしたりせず、直接リーダーを開きます。
そのリーダーを閉じずに、後からライブラリを開くこともできます。

Windows の**設定 → 一般 → 次回以降のウィンドウ起動高速化**では、
**バックグラウンド機能を有効にする**が初期設定でオンです。
最後のウィンドウを初めて閉じる際に、後の起動を速くするため待機を続けることを案内します。
**確認してバックグラウンドで実行**を選ぶとウィンドウだけが閉じ、**JoyRead を終了**を選ぶと完全に終了します。
**次回から表示しない**にチェックを付けて実行の継続を確定すると、次回から案内を省略します。
Esc は閉じる操作を取り消し、ウィンドウを残します。

通知領域のアイコンから JoyRead を再び開けます。
右クリックメニューでは、メイン画面を開く、漫画や PDF をインポートせず読む、
現在の物理メモリ使用量を MB で確認する、再生成可能なメモリキャッシュを消去する、完全に終了する操作ができます。
キャッシュの消去は、すべてのウィンドウとバックグラウンド処理が終了するまで待ちます。
機能をオフにすると、最後のウィンドウを閉じた時点で終了する動作に戻ります。
再びオンにすると案内の省略もリセットされ、次の最後のウィンドウを閉じる際に再表示されます。

同じ Windows 専用グループには**メモリキャッシュを自動消去**と、秒単位の**待機後の消去時間**があります。
自動消去は初期設定でオンで、すべてのウィンドウを閉じてから 60 秒後に実行します。
バックグラウンド処理が残っている場合は完了を待ちます。時間は 1–3600 秒に変更できます。
自動消去をオフにしても、トレイからの手動消去は使えます。
バックグラウンド機能がオフの間は自動消去スイッチが無効になり、両方のスイッチがオンのときだけ時間を設定できます。
既定の読書設定やアーカイブとキャッシュでも、親のスイッチがオフの場合は従属する項目がグレー表示で無効になります。
この機能は Windows ログイン時の自動起動を設定しません。

メイン画面の左側がサイドバー、右側が本棚です。
サイドバーには**本棚**の**すべて、最近、お気に入り、非表示**、**コレクション**、**設定**があります。
左上のツールバーボタンでサイドバーを隠すと、本棚を広く使えます。

## 本を追加する

対応形式は ZIP/CBZ、7z/CB7、RAR/CBR、PDF です。直接開く操作とライブラリへのインポートは役割が異なります。

**インポートせずに開く。** **アクション → 書籍を開く**は、元の場所にあるファイルを直接読みます。
コピーしたり本棚へ追加したりしないため、一時的な読書に向いています。

**ライブラリへインポートする。** **アクション → 開いてインポート**は原本をすぐに開き、
管理用コピーをバックグラウンドで取り込みます。ライブラリにはキャンセルできる進捗ダイアログを表示します。
インポートを中止したり失敗したりしても、リーダーは閉じません。
**アクション → インポート → ファイルをインポート… / フォルダをインポート…**は、読むためのウィンドウを開かずに取り込みます。
本は JoyRead が管理するライブラリへコピーされるため、後から原本を移動・削除してもライブラリのコピーには影響しません。

**フォルダをインポート…**は、初期設定では 1 階層だけ下へたどります。
深いフォルダーに本がある場合は、設定 → 一般の**インポートフォルダーの深さ**を増やしてください。

対応ファイルをライブラリのウィンドウへドラッグすることもできます。
1 ファイルを**読む**領域へドロップすると直接読みます。
同時に取り込みたい場合は、設定 → 一般の**ライブラリの「読む」にドロップしたときにインポート**をオンにします。
ファイルやフォルダーを**インポート**領域へ置くと、読むことなく取り込みます。
読む領域は複数ファイルやフォルダーを受け付けません。
ライブラリが利用できないときは、読む操作に読み取り専用と表示し、インポートを無効にします。

ファイル関連付けの登録後は、OS の**プログラムから開く**で JoyRead を選べます。
この操作と**アクション → 書籍を開く**は、ドロップ時の設定にかかわらずインポートしません。

暗号化された漫画はパスワードを入力して読めますが、インポートはできません。
「開いてインポート」や読む領域からの取り込みが暗号化ファイルに遭遇した場合、取り込みは失敗として表示し、リーダーは残します。
実行中のインポートはライブラリの進捗ダイアログからキャンセルできます。
すでに取り込みが完了した本は、キャンセル後もライブラリに残ります。

### メタデータと本の詳細

漫画アーカイブ内の対応する `meta.json` や `ComicInfo.xml` から、タイトル、著者、タグ、言語を取り込めます。
認識できる項目を使用し、情報がない場合や読めない場合はファイル名や既定値を使います。
これは本に埋め込まれた情報の読み込みであり、オンライン検索ではありません。

**詳細**でタイトルや著者をダブルクリックすると編集でき、Enter で保存します。
Esc またはフォーカスを移す操作で取り消します。言語をダブルクリックして選び直し、表紙をダブルクリックして表紙エディターを開けます。
表紙の編集結果は本とは別に保存します。
ツールバーのカード/リスト切り替えで、表紙中心の表示とコンパクトな一覧を選べます。

### インポート時の変換

ソリッド圧縮の 7z や入れ子のアーカイブは、ページを個別に取り出す処理が重くなることがあります。
JoyRead はインポート時に、対象となる未暗号化アーカイブをライブラリ内の CBZ コピーへ変換できます。原本は変更しません。
この変換と、読書中に使用する再生成可能なページキャッシュは別の機能です。
暗号化ファイルは直接読めますが、インポートできません。

設定 → 一般の**インポート時にアーカイブを変換**で方針を選びます。

| 設定 | 動作 |
| --- | --- |
| 変換しない | インポートしたコピーを元のアーカイブ形式で保持します。 |
| 低速・入れ子形式のみ（初期値） | 必要な低速形式や入れ子形式だけを変換します。 |
| 常に変換 | 通常の ZIP/CBZ も含め、インポート時に変換します。 |

対応アーカイブを読むために変換は必須ではありません。
未変換の本も通常の読書キャッシュを使えます。速度は元の形式と準備済みのキャッシュによって異なります。

## 本棚

本は表紙カードとして表示され、クリックして読めます。その他の操作は本のメニューにあります。

- **読む**：本を開きます。
- **お気に入りに追加 / お気に入りから削除**：お気に入りへの表示を切り替えます。
- **詳細**：タイトル、著者、言語、種類、タグを確認し、表紙を編集します。
- **追加先…**：コレクションへ追加します。
- **エクスポート**：管理中のファイルを指定フォルダーへコピーします。
- **削除（Remove）**：ライブラリの記録だけを取り除き、ファイルは残します。
- **非表示**：[非表示スペース](#非表示スペース)へ移します。
- **削除（Delete）**：ライブラリの記録とアプリ管理下のファイルを削除します。

Delete による削除は元に戻せず、実行前に確認します。Remove は JoyRead の記録だけを削除します。
日本語表示で同じ「削除」と見える場合も、確認内容を読んで対象を確かめてください。

ツールバーの**検索**はタイトルと著者を対象にします。
**並び替え**では追加時刻、タイトル、著者の昇順/降順、または**カスタム**順序を選べます。
形式フィルターは CBZ、CBR、ZIP、RAR、7Z、PDF のいずれかに絞り込み、タグボタンはタグで絞り込みます。
並び替え、フィルター、検索条件は再起動後も保持します。

### カスタム順序と選択

すべて、お気に入り、非表示スペース、各コレクションは、個別に並び替え設定とカスタム順序を記憶します。
最近の本は常に読書時刻で並びます。初めてカスタムを選ぶと、新しく追加した本が先頭になります。
後からカスタムに戻すと保存した順序を復元します。カスタムでは昇順/降順ボタンが無効になります。
新しいメンバーは先頭へ追加します。お気に入りやコレクションから外して再追加した本も先頭になります。
検索、フィルター、非表示の切り替えで保存済みの位置が消えることはありません。

本をクリックすると単独選択し、Shift を押しながらクリックすると選択へ追加、または選択解除します。
本棚の空白やツールバーの空白・タイトル部分をクリックすると選択解除しますが、Shift クリックでは保持します。
空白からドラッグすると矩形選択できます。Shift ドラッグは本の上からでも矩形選択になり、
開始時の選択に矩形と交わる本を追加します。並び替えは開始しません。
矩形選択中もホイールが使え、Esc で操作前の選択へ戻せます。

カスタム順序で並び替えるには、検索、形式フィルター、タグフィルターを解除してください。
選択済みのカードやリスト行をドラッグすると、選択した本を表示順のまままとめて移動します。
未選択の本をドラッグするとその本だけを移動します。並び替える前に Shift を離してください。
破線のプレースホルダーが挿入先を示し、ポインターの横に最大 3 枚のカードと選択数を表示します。

ドラッグ中の自動スクロールは、本棚の上端・下端それぞれ 15% の範囲で働き、端に近いほど速くなります。
プレビューは元のカードの 40% サイズで、ポインターから 5 px 離して表示します。ホイールも使えます。
本の表示領域内でボタンを離すと保存し、領域外で離す、Esc、左ボタンを押したまま右クリックすると取り消します。
一度領域外へ出ても、離す前に戻ることはできます。
本棚、並び替え、表示方式の切り替え、ウィンドウの非アクティブ化、バックグラウンドでの所属・順序変更でも取り消します。
保存中は再度の並び替えを一時的に無効にし、失敗すると最後に保存した順序へ戻してエラーを表示します。

### 表示スケール

ライブラリと独立したリーダーの通常時のサイズを別々に保存します。
最大化、全画面、画面への自動調整はこの設定を上書きしません。
**設定 → 一般 → ウィンドウサイズ → 既定のサイズに戻す**で両方の設定を消去し、
開いているウィンドウを 1200×860 の既定サイズから現在の画面に合わせて調整します。

小さな画面では、システムメニューやタスクバー、Dock の領域を避け、利用可能な領域の左上へ合わせます。
最小サイズはライブラリが 738×600、リーダーが 500×706 です。
画面がこれより小さい場合、右端や下端がはみ出すことがありますが、タイトルバーは操作可能な位置に残ります。
位置、最大化、全画面状態は保存しません。埋め込みリーダーはライブラリのウィンドウを共有します。

展開した検索欄は幅に合わせて縮み、形式・タグフィルターを残します。
設定行に横並びで収まらない操作部はラベルの下へ移り、広げると元に戻ります。

表紙、詳細画面、リーダーのサムネイルは表示スケールに自動対応します。
別のディスプレイへ移動すると、カードの大きさや選択を変えずに画像の解像度を更新します。
編集済み表紙の切り抜き範囲は保持します。高密度画面で古い表紙がぼやける場合は、その画面で原画像から再編集・保存してください。
原画像が見つからない場合は、利用可能なキャッシュ画像を引き続き使います。

読書進行バーにポインターを 180 ms 重ねると対象ページをプレビューし、ハンドルをドラッグすると即座に表示します。
吹き出しは不透明度 80% で、上に画像、下に 1 から始まるページ番号を表示し、リーダーの内側に収まります。
画像を待つ間は小さな読み込み表示とページ番号になります。サムネイルパネルとキャッシュを共有して画像を再利用します。

アプリのウィンドウ内でドラッグを離すと、1 回だけ移動してプレビューを閉じます。
Esc、左ボタンを押したまま右クリック、非アクティブ化、ウィンドウ外での解放は、移動せず取り消します。
通常のホバー終了では 320 ms でフェードアウトし、その間に戻ると即座に復帰します。
ソリッド圧縮やランダム読み出し可否が不明な元データでは、既存キャッシュのみを使用します。
遠いページは通常の読書やバックグラウンドのキャッシュ準備が進むまで読み込み表示になることがあります。
プレビュー自体はアーカイブの展開や事前準備を開始しません。

詳細とリーダーのサムネイルパネルは表示中のページを優先し、スクロールに合わせて先読みを調整します。
戻ると最近見た画像を再利用し、一定のメモリ上限を守るため長い本を丸ごと読み込みません。
詳細、サムネイル、表紙選択画面は、未読み込みの画像の下にも 1 から始まるページ番号を表示します。
画像と番号のどちらでもページを選べますが、項目間の空白はクリック対象ではありません。

メニューはウィンドウ内の空きに応じて方向を変え、右端・下端では左・上へ開きます。
ボタンのドロップダウンも上側へ開けます。長いメニューはスクロールし、省略された文字はツールチップで確認できます。
ウィンドウの移動やサイズ変更でメニューを閉じます。

## コレクション

サイドバーの**本棚**または**コレクション**の見出しをクリックすると折りたたみ・展開を切り替えます。
矢印は折りたたみ時に右、展開時に下を向き、フォーカスのある見出しは Enter・スペースでも操作できます。
押している間は暗くなり、外へドラッグすると表示を解除し、外で離すとクリックを取り消します。
どちらも初期状態は展開で、再起動後も状態を記憶します。
折りたたんでも現在の本棚や選択は変わらず、コレクションを折りたたむと作成項目も隠れます。
設定は下部に残ります。非表示スペースの表示は、展開し直した場合もプライバシー設定に従います。

コレクションはシリーズ、特集、未読リストなどを手動でまとめる機能です。
サイドバーの**新規コレクション**から追加し、本の**追加先…**メニューで登録します。1 冊を複数のコレクションに所属させられます。
コレクションの削除はグループだけを削除し、本はライブラリに残ります。
本と一緒にコレクションを非表示にする方法は[非表示スペース](#非表示スペース)を参照してください。

## タグ

本の**詳細**のタグパネルでは、上部にその本のタグ、下部にライブラリの既存タグを表示します。
検索欄で Enter を押す操作は既存タグを絞り込むだけで、新しいタグは作成しません。

作成するには**設定 → タグ**を開き、検索を解除してからタグ一覧の末尾にある**＋**をクリックします。
別に表示されるタグ名の入力欄に名前を入力し、確認ボタンをクリックするか、その入力欄で Enter を押してください。
作成後、本のタグパネルへ戻って割り当てます。
本ごとに同じ名前のタグを使うと、ツールバーのタグフィルターから探しやすくなります。

**設定 → タグ**では、ライブラリ全体のタグをまとめて改名・削除できます。
削除すると、そのタグを持つすべての本からタグを外しますが、本は変更しません。
タグダイアログの応答性を保つため、1 ライブラリの上限は 5,000 個です。

## 読書

本をクリックして開きます。初期設定ではメインウィンドウ内に表示します。
**設定 → 一般 → 独立した読書ウィンドウ**をオンにすると本ごとに別ウィンドウを使い、並べて比較できます。

### ページ移動

| 入力 | 動作 |
| --- | --- |
| ← / → | 読む方向に従って前後のページへ移動します。 |
| ↑ / ↓ | 縦長ページの中を上下に移動し、縦モードでは連続スクロールします。 |
| ホイール・トラックパッド | 縦長ページの中を移動し、縦モードでは連続スクロールします。 |
| 右クリック | 読書用の操作部を表示します。 |
| F | 読書中に全画面表示へ入ります。 |
| Esc | 全画面を終了し、パネルを閉じ、またはリーダーから戻ります。 |

ポインターの動きを止めると、しばらくして上部バーとページバーが消えます。動かすか右クリックすると再表示します。
メインウィンドウ内のリーダーから戻る場合も全画面を終了します。全画面中に最大化ボタンを押す操作でも戻れます。
全画面中はページと読書バーの外周を角丸なしで表示し、戻ると通常の角丸を復元します。

### レイアウト

歯車から**リーダー設定**を開きます。**横モード**・**縦モード**は本ごとの設定で、
独立した先読み設定はすべてのリーダーへ共通に適用します。

- **読む方向**：右から左、左から右、上から下。
- **カスタムを有効化**：横・縦それぞれにスイッチがあり、対応するスイッチがオンの間だけ従属項目が適用されます。
- **単ページ**：オフにすると、収まる場合に自動で見開きを使えます。横長のページは単独表示し、表紙や見開き画像を分割しません。
  先頭の単ページなどで以降の組み合わせがずれる場合は、**見開きのペアをずらす**で全体を 1 ページずらせます。
- **フィットモード**：自動、高さに合わせる、幅に合わせる、ページに合わせる。
- **余白**：縦モードで上下に並ぶページ間の距離。0–200 px で設定します。
- **ズーム**：縦モードの倍率。25%–200% で、縦の「幅に合わせる」がオンの間は無効です。
- **ページ切り替え効果**：なし、またはスライド。

横方向の読書で**幅に合わせる**を使うと、縦長ページは先頭から表示します。
ホイール、トラックパッド、↑ / ↓ で続きを見られ、キーを押し続けると繰り返し移動します。ページの端で止まります。
← / → は通常どおりページをめくり、新しいページの先頭を表示します。
サイズ変更や全画面の切り替えでは、ページの範囲内で可能な限り位置を維持します。
高さが収まるページは中央表示のままです。パネルやダイアログを開いている間は上下移動のショートカットは働きません。

先読みの初期値は**前 4 ページ、後 8 ページ**で、設定範囲は**0–10**と**0–20**です。
前後はページ番号の大小を指し、左右の読書方向に依存しません。
見開きでは表示中の組の外側から数え、縦モードでは現在位置を基準にしつつ、表示に必要なページを必ず読み込みます。
0 はその側のバックグラウンド先読みだけを止め、表示に必要な読み込みは止めません。
変更は開いているすべてのリーダーへ反映し、再起動後も保持します。
範囲を狭めると待機中の要求を入れ替えますが、有用なキャッシュや開いている本は保持します。
ページキャッシュのメモリ上限は引き続き適用されるため、指定した全ページの常駐を保証する値ではありません。

### 長い本の中を探す

読書用の操作部から、次の 3 パネルを開けます。

- **目次**：本に含まれる目次。PDF にはよくありますが、多くの CBZ にはありません。
- **サムネイル**：各ページを小さな画像で表示し、覚えている場面を探せます。
- **しおり**：自分で付けた位置の印。次の節を参照してください。

ライブラリの本は読書位置を保存し、再度開くとそこから表示します。
インポートせずに開いたファイルには、ライブラリの読書位置、しおり、本ごとの保存設定を作りません。

## しおり

ライブラリの本では、読書用の操作部から現在のページにしおりを追加できます。
初めは既定の名前で作成し、**しおり**パネルで改名・削除できます。
しおりは本のファイルではなくライブラリに保存し、アーカイブを変更しません。
保護するには、バックアップにライブラリのデータベースを含めてください。

## 表紙

初期状態では最初のページを表紙に使います。変更するには本の**詳細**で表紙編集を開きます。

- **本のページから選択**：本の好きなページを選びます。
- **画像取込**：ディスク上の画像ファイルを使います。

確定前に切り抜きと位置を調整できます。原本を変更せず、ライブラリの記録と一緒に別保存します。

## 非表示スペース

本のメニューで**非表示**を選ぶと、すべて、最近、お気に入り、検索結果から外し、サイドバーの**非表示**へ移します。
コレクションも右クリックメニューの**非表示可能にする**で、そのコレクションと所属する本を隠します。
**通常に戻す**で解除できます。

初めて開くときにパスワードを設定し、その後はセッションごとに入力を求めます。
その他の操作は**設定 → プライバシー → 非表示スペース**にあります。
**コレクションを表示**は非表示対象のコレクションをサイドバーに出すかを指定し、
**パスワード変更**で更新、**すべて元に戻す**で非表示を一括解除できます。

これは、人に見られるかもしれない本棚から本を隠す機能であり、**暗号化ではありません**。
ファイルは通常の本と同じように保存され、システムのアカウントとファイルブラウザーにアクセスできる人は読めます。
パスワードが制限するのは JoyRead の画面だけです。暗号化が必要な場合は、暗号化ディスクイメージやフルディスク暗号化を利用してください。

同じ設定内の**リセットして消去**は、非表示の本をディスクから永久に削除し、
非表示対象のコレクションとパスワードも消します。元に戻せず、先に `delete` と入力する必要があります。

### 一般

| 設定 | 初期値 | 内容 |

| 言語 | システムに従う | システム言語、または English・日本語・简体中文を選びます。 |
| ライブラリの「読む」にドロップしたときにインポート | オフ | 読む領域へ置いた 1 ファイルを同時に取り込みます。書籍を開く・OS から開く操作は読み取りのみです。 |

| インポートフォルダーの深さ | 1 | フォルダー取り込み時にたどる深さ。 |
| インポート時にアーカイブを変換 | 低速・入れ子形式のみ | [インポート時の変換](#インポート時の変換)を参照。 |

**ライブラリを検証してキャッシュを削除**については[問題が起きたとき](#問題が起きたとき)を参照してください。
Windows のバックグラウンドと自動消去は[はじめに](#はじめに)で説明しています。

### 既定の読書設定

最初の読書方向、横・縦のカスタマイズ、単ページ、フィットモード、縦の余白と倍率、ページ切り替え効果を指定できます。
一時ファイルと、本ごとの設定がまだないライブラリの本に適用します。保存済みの個別設定が優先されます。
変更は次回以降に開くリーダーへ適用し、すでに開いているリーダーの設定を上書きしません。
現在の本はリーダー設定から変更してください。共通の先読みは別設定です。[レイアウト](#レイアウト)を参照してください。

### アーカイブとキャッシュ

初期値は一般的なライブラリ向けです。非常に大きな本を読む場合は必要な上限を増やし、使用資源を減らしたい場合は下げてください。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| アーカイブサイズを制限 / 最大アーカイブサイズ | オン、5 GB | 上限を超えるアーカイブを開きません。 |
| リソース保護 | オン | 次の 4 項目の制限をまとめて切り替えます。 |
| 抽出項目の最大サイズ | 1 GB | 展開する 1 ページの最大サイズ。 |
| 操作あたりの最大抽出データ | 4 GB | 1 回の展開処理で取り出すデータの合計上限。 |
| 最大画像サイズ | 400 MP | 400 メガピクセルを超える画像を拒否します。 |
| 外部展開のタイムアウト | 300 s | 内蔵 7-Zip を実行できる最長時間。 |
| ネストされたアーカイブの深さ | 2 | アーカイブ内のアーカイブをたどる深さ。 |
| アーカイブ全体のファイル深度 | 100 | 本全体のパスの入れ子深度の上限。 |
| リーダーページキャッシュ（メモリ） | 512 MB | メモリに保持するデコード済みページ。 |
| サムネイルキャッシュ（メモリ） | 64 MB | メモリ内のサムネイル。 |
| アーカイブ展開プール（ディスク） | 5 GB | 展開したページキャッシュのディスク予算。 |
| アーカイブキャッシュ戦略 | Zip bundle | 本ごとに 1 ZIP として保存するか、個別の隠し画像ファイルを使います。 |

アーカイブの申告サイズは必ずしも正確ではありません。2 KB と記載された内容が、展開後に数 GB になる場合もあります。
この制限により、不正・破損アーカイブがメモリやディスクを使い切る前に、エラーとして処理を止められます。

**展開プール使用量**は使用中のディスク予算を示し、**クリア**で空にできます。
満杯になると、最も長く使われていない本のキャッシュから削除し、必要時に再生成します。
そのため通常は手動で空にする必要はありません。

**非表示スペース**：コレクションを表示、パスワード変更、すべて元に戻す、リセットして消去。

## ファイルの保存場所

以下はインストール版の既定の場所です。ライブラリを移動したり別のものを選択したりした場合は、
**設定 → プライバシー → ストレージ → ライブラリの場所**に表示される実際のパスを確認してください。

### macOS

| 内容 | 場所 |
| --- | --- |
| ライブラリ：本・表紙・データベース・バックアップ | `~/Library/Application Support/JoyRead-Library` |
| 設定ファイル | `~/Library/Application Support/JoyRead/Config/settings.json` |
| ログ | `~/Library/Application Support/JoyRead/Logs` |
| 再生成可能なアーカイブページキャッシュ | `~/Library/Caches/JoyRead` |

### Windows

| 内容 | 場所 |
| --- | --- |
| ライブラリ：本・表紙・データベース・バックアップ | `%APPDATA%\JoyRead\JoyRead-Library` |
| 設定ファイル | `%APPDATA%\JoyRead\JoyRead\Config\settings.json` |
| ログ | `%APPDATA%\JoyRead\JoyRead\Logs` |
| 再生成可能なアーカイブページキャッシュ | `%LOCALAPPDATA%\JoyRead\JoyRead\Cache` |

これらのパスはエクスプローラーのアドレスバーへ貼り付けられます。
`%APPDATA%` は通常 `C:\Users\<username>\AppData\Roaming`、
`%LOCALAPPDATA%` は `C:\Users\<username>\AppData\Local` を指します。
設定やキャッシュのパスで `JoyRead\JoyRead` が繰り返されるのは、実際のディレクトリ構造です。

### Ubuntu / Linux

| 内容 | 場所 |
| --- | --- |
| ライブラリ：本・表紙・データベース・バックアップ | `~/.local/share/JoyRead-Library` |
| 設定ファイル | `~/.config/JoyRead/Config/settings.json` |
| ログ | `~/.config/JoyRead/Logs` |
| 再生成可能なアーカイブページキャッシュ | `~/.cache/JoyRead` |

`~` は現在のユーザーのホームディレクトリです。環境変数が設定されている場合、
`XDG_DATA_HOME` が `~/.local/share`、`XDG_CONFIG_HOME` が `~/.config`、
`XDG_CACHE_HOME` が `~/.cache` に代わります。ログは上表の設定ディレクトリ配下にあります。

### ライブラリの内容と移動

ライブラリ内の `Books/` に管理中の本、`Database/joyread.sqlite3` にデータベースの記録、
`Thumbnails/` に表紙とサムネイル、`Backups/` にバックアップを保存します。
ログディレクトリには `joyread.log` とローテーション済みログがあります。
カスタム翻訳は `settings.json` と同じ設定ディレクトリの `Config/locales/` に置きます。

ソースチェックアウトから起動する場合や `JOYREAD_RUNTIME_DIR` で実行用ディレクトリを指定した場合は、
その下の `JoyRead-Library/`、`.joyread_support/`（設定とログ）、`.joyread_cache/` を使用します。

インポートせずに開いた本はここにはなく、元の場所に残ります。

**設定 → プライバシー → ストレージ → ライブラリの場所**は、本、表紙、データベース、バックアップを別の場所へ移動します。
外付けドライブも指定できます。ページキャッシュはアプリのキャッシュ場所に残り、必要時に再生成します。
ライブラリから開いたリーダーは位置を保存して閉じてから移動し、独立して開いた外部リーダーは残します。
**既存のライブラリを選択**は、手で移動したライブラリを指定し直す場合や、複数のライブラリを切り替える場合に使えます。
管理中の本や保存済み進行情報を使うリーダーは、以前 OS から同じウィンドウを再表示した場合も、この操作中に閉じます。

## 暗号化アーカイブ

パスワード付きの 7z、RAR、ZIP を読めます。開くときに入力し、そのセッションでだけ使い、パスワードを保存しません。

暗号化アーカイブには次の制限があります。

**キャッシュページは暗号化されません。** 読み込みを速くするために展開したページはディスクへ平文で保存します。
**設定 → プライバシー → 閉じるときにキャッシュしたページを削除**は初期設定でオンで、セッション終了後に残さないようにします。
ただし本を開いている間は、キャッシュディレクトリにアクセスできるプログラムから読めます。

**パスワードがローカルのプロセス情報に一時的に見えます。** 内蔵 7-Zip はコマンドライン引数でパスワードを受け取ります。
展開中は、同じユーザーで動く別プロセスが `ps` などで読み取れる場合があります。
対象は 7z、RAR、旧 ZipCrypto 暗号化の ZIP です。

AES 暗号化 ZIP には、このコマンドライン上のパスワード露出はありません。
外部プログラムを起動せず JoyRead 内で復号します。ZipCrypto はアプリ内の遅い復号を避けるため外部ヘルパーを使用します。
自分だけが使うパソコンと共有するパソコンでは、この制限の影響を区別して考えてください。

## 問題が起きたとき

**ライブラリを読み込めない。** フォルダーが利用できない場合、本棚に保存済みのパス、理由、再試行と今回スキップの選択肢を表示します。
データベースの読み込み失敗では同じ選択肢をダイアログに表示します。
スキップしても保存した場所は保持され、外部ファイルを開けます。
**設定 → プライバシー → ストレージ → 既存のライブラリを選択**から別の有効なライブラリを選べます。
起動時に既存の壊れたライブラリを勝手に消去・リセットすることはありません。

**リソース上限を超えたというエラー。** アーカイブとキャッシュの制限のどれかを超えています。
表示された上限を増やすか、信頼できるファイルの場合にリソース保護をオフにしてください。

**本が見つからないと表示される。** ファイルを発見できません。取り込んだ本ではライブラリの移動がよくある原因です。
[ライブラリの場所](#ファイルの保存場所)を確認してください。記録を削除するか残すかを選べます。

**本が利用できないと表示される。** 整合性検査で、取り込み時からファイルが変わったことを検出しました。
予期しない変更は破損の可能性があるため開きません。本のメニューから記録を取り除き、再インポートしてください。

**ページ移動が遅い。** ソリッド 7z、RAR などで、変換やキャッシュが未準備の可能性があります。
インポート可能な未暗号化ファイルでは、**インポート時にアーカイブを変換**を**常に変換**にして再度取り込み、
展開プールに余裕があるか確認してください。暗号化ファイルは直接読むことだけができ、インポート変換は使えません。

**情報が食い違う。** **設定 → 一般 → ライブラリを検証してキャッシュを削除**は、現在のライブラリについて、
変更済み、重複、欠落、孤立したファイルや未使用の生成表紙を検査します。結果を表示してから変更の確認を求めます。
共有のアーカイブページキャッシュには独立した容量上限があり、アーカイブとキャッシュ設定から消去できます。

**EPUB を開けない。** 機能が未完成のため、現在は無効です。[README](../README.ja.md)を参照してください。

## アプリの言語

**設定 → 一般 → 言語**で、システムに従う、English、中文、日本語を選べます。
新規インストールでは Windows、macOS、Ubuntu/Linux の UI 言語設定に従い、対応言語がなければ英語を使用します。
中国語の地域・文字体系の違いは、現在すべて簡体字中国語にまとめます。更新時には既存の言語選択を保持します。
システムに従う設定は起動時と選択時に検出し、その後の OS 言語変更を反映するには再起動が必要です。

変更は開いているウィンドウと操作部へ反映します。アプリ内の名前は中国語が「欣阅」、英語が JoyRead、日本語が「ジョイヨミ」です。
インストールされたショートカット、実行ファイル、ライブラリ・設定ディレクトリの名前は変わりません。
OS 標準のファイルダイアログのボタンは、OS の言語になる場合があります。

固定の設定ディレクトリ `Config/locales` に置いた JSON 翻訳は、項目ごとに内蔵訳を上書きします。
省略・空欄の項目は内蔵訳を使い、内蔵訳がない場合は英語へ戻します。
壊れた上書きファイルは無視してログへ記録します。
ユーザーが入力したタイトル、タグ、ヒント、パス、技術的な診断情報は変更しません。
